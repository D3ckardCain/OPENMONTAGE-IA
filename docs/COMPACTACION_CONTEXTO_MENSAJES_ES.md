# Compactación determinista de contexto conversacional

La sesión conserva `agent_session.json` como historial de trabajo y deja los originales compactados en `artifacts/agent_context_<sha256>.json`. Cada archivo guarda el mensaje completo y su hash; el mensaje en línea se reemplaza por una referencia con rol, clasificación y ruta recuperable con `read_artifact` usando `archive_name`.

La reducción solo se intenta cuando el contexto serializado supera 90.000 caracteres y el lote de herramientas terminó. No se compactan los 16 mensajes más recientes, instrucciones del sistema, mensajes `tool`, respuestas `assistant` que contengan llamadas ni sesiones con una llamada en vuelo. Los recibos `tool` además deben corresponder a un `tool_call_id` previo y estar dentro del límite persistido `model_consumed_message_count`: ese contador solo avanza después de que una respuesta correcta del modelo haya consumido el historial anterior. Por eso un resultado recién generado permanece íntegro para la siguiente llamada, incluso al reanudar. Mensajes que contienen autorizaciones, decisiones, planes, tareas, negaciones, hechos declarados, resultados, referencias (URL, issue, commit o ruta) o señales de intento incierto quedan íntegros en línea. Esta lista es deliberadamente conservadora y determinista; no interpreta el significado de texto libre.

Un mensaje de usuario reemplazado queda etiquetado como afirmación del usuario no verificada; un mensaje del asistente, como texto del asistente que no constituye evidencia. El marcador no promueve una afirmación, plan o resumen a hecho ni concede autorización vigente. El original conserva rol y contenido exactos en el archivo. Llamadas/respuestas emparejadas y recibos de herramientas se mantienen con sus identificadores.

En la reanudación, se comprueba la versión y la identidad de las referencias archivadas. Un cambio del contenido bloquea la sesión con `AGENT_CONTEXT_ARCHIVE_CHANGED`; un cambio de contrato bloquea con `AGENT_CONTEXT_VERSION_CHANGED`. Si no se puede escribir o verificar el archivo, el mensaje original no se reemplaza. El límite agregado de archivo es 256 MiB para recibos y mensajes; al alcanzarlo la compactación se detiene sin borrar evidencia.

El umbral mide caracteres, no tokens. No hay resumidor semántico ni inferencia en esta ruta; tampoco se acredita memoria tipada entre proyectos, fidelidad de una sesión larga o medición de tokens del modelo. Para recuperar el texto original, lee el nombre indicado en `archive_name` y verifica `message_sha256`.
