# Del buscador al productor local

Selecciona «Crear producción con esta referencia» en una publicación coincidente. El estudio recibe su URL y un encargo editable con el canal, tema, vistas públicas acumuladas observadas e idioma de audio declarado cuando exista. No se transfiere ni supone monetización, RPM o crecimiento real.

El borrador propone investigación adicional, guion y recursos propios o autorizados, localización cultural y comprobación del idioma original antes de elegir los idiomas de destino. El título empieza por «Nuevo enfoque» para distinguir el proyecto del título de referencia. Revisa el encargo y el idioma del formulario antes de crear el proyecto.

Si seleccionas el canal completo, el encargo pide elegir primero una publicación concreta: el canal no se trata como un archivo de video. La muestra del buscador puede ser parcial.

Abrir el estudio no crea un proyecto ni inicia descargas, análisis, modelos o publicación. Crear el proyecto conserva el encargo en su solicitud; después se inicia explícitamente el productor local, con sus controles habituales.

Las pruebas de navegador usan respuestas sintéticas. No validan acceso a YouTube, las credenciales reales ni la calidad de una producción.
